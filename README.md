## Installation
To install AiFlow, run the following command:

```bash
pip install -e .
```

## Usage
AiFlow contains multiple powerful models: **Hanasu TTS**, **Hifi Gan**, **Yuna Audio**, and **Yuna VLM**, etc. Refer to Colab notebooks to see how to see the models.
